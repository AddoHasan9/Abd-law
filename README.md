# نظام مكتب المحامي عبد الحسن الخزرجي

نظام إدارة معاملات ومهام مكتب المحاماة — Next.js 15 + Supabase.

## التشغيل المحلي

```bash
npm install
cp .env.local.example .env.local   # املأ مفاتيح Supabase
npm run dev
```

يفتح على http://localhost:3000

## قبل أول تشغيل

نفّذ ملفات SQL في Supabase بالترتيب (راجع `SUPABASE-SETUP.md`):
1. `supabase-schema.sql`
2. `supabase-seed.sql` — اختياري للتجربة
3. `supabase-storage.sql`

## البنية

```
app/            صفحات ومسارات Next.js (App Router)
components/     مكوّنات الواجهة
lib/
  supabase/     عملاء الاتصال: client (متصفح) · server · admin
  data/         استعلامات مجمّعة حسب الكيان
  constants.ts  منطق العمل: الأنواع، الغرامة، سير العمل، الصلاحيات
types/          أنواع تطابق مخطط القاعدة
styles/         نظام التصميم (متغيّرات الثيم)
middleware.ts   حارس الجلسة والمسارات
```

## قواعد ملزِمة

**اللون له معنى:** الأزرق = البنية والتنقّل · الأخضر = الإنجاز والفعل.
لا يُستعمل الأخضر للتنقّل ولا الأزرق لأزرار الإنجاز.

**الأمان:** كل جدول محمي بـ RLS. المفتاح `service_role` لا يُستورد
في أي مكوّن عميل إطلاقاً — استعماله في Route Handlers فقط.

**منطق العمل مصدره واحد:** قواعد الغرامة وسير العمل معرّفة في
`lib/constants.ts` وفي دوال القاعدة معاً. عند تغيير أي قاعدة، حدّث الاثنين.
